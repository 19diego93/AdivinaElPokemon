Esto es un proyecto de un estudiante que está aprendiendo react con typescrip, utiliza bootstrap 5 en este proyecto, trata de minimizar los estilos personalisados y trata de utilizar las clase de Bootsrap siempre que sea posible.
El estudiante trabaja con useState, useEffect y useCallback, no agregues más hooks.
Siempre prioriza que el codigo sea facil de entender y siga las mejores prácticas de React, que sea facil para un estudiante aprendiendo react y typescrip.
Mantén el proyecto como SPA sin enrutamieniento.
Limita el uso de librerias externas , utiliza solo las que son necesarias para el proyecto.
